Instantiation Code

JavaScript 
const slider = new ImageSlider('#emerald-slider', {
  autoplay: true,
  autoplayInterval: 3000,
  transitionSpeed: 600,
  showArrows: true,
  showDots: true
});

Continuous Boundary Loop

Utilizes dynamic start/end DOM slide duplication to perform seamless wrapping animations in the same translation direction.

Fluid Touch gestures

Unifies mobile touch points and desktop mouse drags using standard pointer tracking calculations for frictionless sliding responsiveness.

Hardware Accelerated

Uses CSS transform: translateX() rendering offloaded to device GPU pipelines for continuous 60fps frame rate executions.
